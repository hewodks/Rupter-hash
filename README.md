# Rupter-hash
Comparativo de Hashes basado en python, version mejorada a la anterior

El proyecto cuenta con las bases para su funcionamiento normal y para el que fue creado principalmente.

1- comprobar si tus contraseñas son realmente seguras comprobandola mediante una wordlist de miles de contraseñas filtradas

2- Comprobar si un hash conseguido SHA-256 es debil con capacidad de aplicarle un reversible para conseguir su contraseña en plano

sin embargo la idea de este proyecto es lograr crear una suite dedicada a manejar diferentes modelados de encriptado, Decodificar wordlist que contienen contraseñas en HEX, dos diferentes flujos de comparacion aparte de la original por problemas de Alto consumo de RAM.
